# Pure/const state in the name sets, implementation plan (AR4 stage 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline, one implementer). Steps use checkbox (`- [ ]`) syntax.

**Goal:** `pure`/`const` live only in `CSym.aset`; exclusion lives only in `attr_excl_tab` + `attr_excl_generic` gated by declaration kind; `CSF_PURE`, `CSF_CONSTFN`, the six `AttrState` fields and `attr_excl` are gone; a guard fails on a new `CSF_*` mirror of an `attrs.def` attribute.

**Architecture:** four commits, each leaving the suite green: the set-based predicate for call equality (flags still written), the kind gate on the table, the unification of pure/const into the generic path (deletes the flags and adds the guard in the same commit, so its allowlist starts at the seven kept mirrors), then docs and the gate.

**Tech Stack:** C99 (`src/c/`), sh/awk guard (`bench/tools/`), the WSL gate (`docs/S1_PLAN.md` "Closing a slice"), gcc 15.2 in WSL as the oracle.

**Spec:** `docs/PURE_CONST_DESIGN.md` (read it first: "Behaviour changes" binds every task; prototype `proto-y1` is the shape, not a patch to apply).

## Review Focus

1. `int (*fp)(int) __attribute__((pure)); ... fp(x) == fp(x)` stays silent (set records `pure` on a variable; the predicate's `CS_FUNC` test, golden `attr_pure_const_call`).
2. A variable named like a pure built-in is not pure (`ccall.c:1622` early return stays; re-check by grep in Task 1).
3. A redeclaration without the attribute keeps call equality after the flags are gone (set carried by `attrs_names`), also after a definition and after `copy` (golden `attr_pure_const_call`).
4. `noreturn, copy(p)` and `copy(p), noreturn` with `p` pure conflict as gcc does through the merged copy loop; `st->nonnull |= r->nonnull` still copies for functions (golden `attr_pure_const_copy`; nonnull through `copy(t)` is `attr_copy_excl` line 27).
5. `common, nocommon` on an object still conflicts after the `obj` gate (golden `attr_excl_variable`, mutant-checked). On a typedef, field or parameter it never reached the table (`cdecl.c:2389`) and is green before and after; on a function it now prints nothing where gcc prints "ignored" twice, so it is not in any golden (parked).

## End-state fit

Home: `cattr.c` (`attr_excl_tab`, `attr_excl_generic`, `attrs_copy_check`) owns exclusion; `CSym.aset` owns the fact; `cdecl_fn_pure` beside `cdecl_aset_has` is its one reader for calls; `bench/tools/attr_lists.sh` owns the guard. Deletes all of those; nothing is kept beside the new shape. Unchanged and parked with evidence: the seven kept mirrors (allowlisted), the `Attrs` bools, handler dispatch.
